# 개요

Dependency Cruiser를 활용하여 gitlab runner 시점에서 시각화를 통해 컴포넌트간(or 모듈)의 의존성을 확인하고 빠르게 대응하기 위해 시도해 보았어요.

# 설치

graphviz를 기반으로 시각화를 하기 때문에 각 환경에 맞는 graphviz를 설치해야 해요.

- mac
```shell
# homebrew 사용시
brew install graphviz

sudo port install graphviz
```

- linux
```shell
# Debian, Ubuntu
sudo apt install graphviz
```

- window
https://graphviz.org/download/ (버전에 맞는 파일을 설치 해주세요.)



graphviz를 설치했으면 이제 라이브러리를 추가해 볼게요

```shell
# npm
npm install --save-dev dependency-cruiser
# yarn
yarn add -D dependency-cruiser
# pnpm
pnpm add -D dependency-cruiser
```


# 사용

라이브러리를 설치했으니 이제 현재 프로젝트의 의존성 그래프를 만들어 볼게요
우선, 초기 세팅을 위해서 초기화를 하여 설정 파일을 만들어야 해요

```shell
npx depcruise --init
```


프로젝트 설정에 맞게 옵션을 선택하면 자동으로 설정 파일이 생겨요. 그럼 이제 시각화 파일을 만들어 볼게요
```shell
npx depcruise src --include-only '^src' --config --output-type dot | dot -Tsvg > dependency-graph.svg && open dependency-graph.svg
```

![](https://velog.velcdn.com/images/r_eum/post/c092d67f-4519-4fe1-b702-7aced1faf85b/image.svg)
생성된 의존성 그래프

이렇게 src 디렉토리를 기준으로 각 파일들의 의존성 시각화가 만들어져요. 그럼 이제 이걸 Gitlab runner를 이용해 코드리뷰 시점에 확인할 수 있도록 해보려고 해요.



### Merge Request에 의존성 그래프 추가
![](https://velog.velcdn.com/images/r_eum/post/838b4025-939b-456d-917e-953358880e4d/image.png)

복잡한 프로젝트의 경우에는 HTML 버전으로 확인하여 인터렉티브한 환경으로 확인할 수 있어요.
![](https://velog.velcdn.com/images/r_eum/post/06e6bf66-2b62-419c-912a-4848aed99e12/image.png)


## 결론

프로젝트 시각화를 하고 코드를 파악 하는 시간이 줄어들 수 있을것 이라고 생각해요. 잘못된 참조를 파악할 수 있고 참조 경로를 통해 사이드 이펙트를 찾는 시간이 획기적으로 감소하는 효과를 기대해요.
